# Estilo Conforto Store App

Este projeto é uma aplicação web chamada "Estilo Conforto Store". Abaixo estão as informações sobre a estrutura do projeto e suas funcionalidades.

## Estrutura do Projeto

```
FrontEnd
├── public
│   └── index.html          # Ponto de entrada principal da aplicação
├── src
│   ├── assets
│   │   ├── image           # Pasta para armazenar imagens utilizadas no projeto
│   │   └── style
│   │       └── login.css   # Estilos CSS específicos para a página de login
│   ├── pages
│   │   └── login.html      # Estrutura HTML da página de login
│   └── styles              # Pasta para estilos adicionais da aplicação
│   │   └── login.css       # Estilo CSS da página de login
├── .gitignore              # Arquivo que especifica arquivos a serem ignorados no repositório
└── README.md               # Documentação e informações sobre o projeto
```
